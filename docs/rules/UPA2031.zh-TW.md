# UPA2031 — Discarded infinite tween without SetLink

> [English](UPA2031.md) | 繁體中文

| | |
|---|---|
| 類別 | Ecosystem |
| 預設嚴重度 | Warning |
| 預設啟用 | 否 |
| 生效條件 | assembly 引用了 DOTween |

## 成因

一條 fluent 鏈建立了無限 tween——以負的常數迴圈次數呼叫 `SetLoops`——
且鏈的結果被丟棄(該陳述式是單獨的 expression statement),
鏈上也沒有任何 `SetLink` 呼叫。

## 規則說明

兩項 DOTween 文件記載的行為在此疊加:auto-kill 會在 tween 完成時將其銷毀,
而負的迴圈次數會讓 tween 無限循環
([DOTween 文件](https://dotween.demigiant.com/documentation.php))。
無限 tween 不會到達完成狀態,所以 auto-kill 不會觸發。當鏈的結果又被丟棄時,
沒有任何程式碼持有可以 kill 這個 tween 的句柄:它會在 target 銷毀後繼續執行,
既浪費每幀的工作量,也會依 safe mode 設定表現為錯誤或洩漏。

`SetLink(gameObject)` 會把 tween 的生命週期綁定到一個 GameObject,
在該物件銷毀時將 tween 一併 kill
([DOTween 文件](https://dotween.demigiant.com/documentation.php))——
帶有 `SetLink` 的鏈正因如此而豁免。

不回報:

- 鏈的結果被儲存、作為引數傳遞、被回傳或被 yield——取得結果的一方可以自行
  kill 這個 tween。
- 鏈上任何位置含有 `SetLink`。
- 有限的迴圈次數,以及非編譯期常數的迴圈次數。

本規則在任何位置都會回報,不限於熱路徑——洩漏的無限 tween 無論在哪裡建立,
代價都相同。它**只在 assembly 引用 DOTween 時執行**(免費版與 Pro 版都附帶
同名的 assembly),並且仍**預設停用**(生態規則群的政策);由 preset 啟用。

## 如何修正

其一,儲存 tween 並隨其擁有者一起 kill:

```csharp
Tween _spin;

void Start()
{
    _spin = transform
        .DORotate(new Vector3(0f, 360f, 0f), 2f, RotateMode.FastBeyond360)
        .SetLoops(-1);
}

void OnDestroy()
{
    _spin.Kill();
}
```

其二,把它的生命週期連結到 GameObject:

```csharp
void Start()
{
    transform
        .DORotate(new Vector3(0f, 360f, 0f), 2f, RotateMode.FastBeyond360)
        .SetLoops(-1)
        .SetLink(gameObject);
}
```

## 何時抑制

當 tween 的生命週期確實由其他地方管理時可予以抑制——例如它透過 `SetId`
帶有 ID,並由管理者以 `DOTween.Kill(id)` 統一 kill。analyzer 不追蹤
跨方法的生命週期管理。

## 如何設定或抑制

- 啟用本規則(預設關閉):在 `.editorconfig` 設定 `dotnet_diagnostic.UPA2031.severity = warning`
- 單一呼叫點:以 `#pragma warning disable UPA2031` / `#pragma warning restore UPA2031` 包住
- 整個專案:設定 `dotnet_diagnostic.UPA2031.severity = none`

## 可設定項

無。

## 相關規則

- UPA2032 回報字串 tween ID(同屬 DOTween 規則群)。
