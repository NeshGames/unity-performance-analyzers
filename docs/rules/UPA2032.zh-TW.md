# UPA2032 — String tween ID

> [English](UPA2032.md) | 繁體中文

| | |
|---|---|
| 類別 | Ecosystem |
| 預設嚴重度 | Info |
| 預設啟用 | 否 |
| 生效條件 | assembly 引用了 DOTween |

## 成因

把 `string` 型別的引數傳給 `SetId(...)`,或傳給 `DOTween` 的靜態過濾操作之一:
`Kill`、`Play`、`Pause`、`Restart`、`Rewind`、`Complete`、`Flip`、`Goto`、
`TogglePause`、`IsTweening`。

## 規則說明

DOTween 的靜態過濾操作作用於符合某個 ID 或 target 的那部分作用中 tween。
依 DOTween 文件所述,以 `int` 或 `string` ID 過濾能讓這些操作快上許多,
其中 `int` 又比 `string` 更快
([DOTween 文件](https://dotween.demigiant.com/documentation.php))。
因此字串 ID 是「快速過濾選項」中最慢的一種——而且作為一般字面值,
它對打錯字沒有任何編譯期防護。

本規則為 **Info** 嚴重度:字串 ID 是 DOTween 支援的用法,
其差異只在過濾操作執行頻繁時才有影響。

不回報:

- `int` ID 與物件 ID。
- 以 target 參考過濾(`DOTween.Kill(transform)`、`transform.DOKill()`)。
- reduced 擴充方法呼叫的接收者——它是 tween 或 target,不是 ID 引數。

本規則**只在 assembly 引用 DOTween 時執行**(免費版與 Pro 版都附帶同名的
assembly),並且仍**預設停用**(生態規則群的政策);由 preset 啟用。

## 如何修正

```csharp
// 回報:字串 ID 是快速過濾選項中最慢的一種。
tween.SetId("player-move");
DOTween.Kill("player-move");

// 較佳:int ID。
const int PlayerMoveId = 1;
tween.SetId(PlayerMoveId);
DOTween.Kill(PlayerMoveId);

// 或改以 target 參考過濾,不用 ID。
transform.DOKill();
```

## 何時抑制

在可讀性或除錯便利比過濾速度更重要的地方,或過濾操作執行頻率很低的地方
(場景收尾、一次性的 UI 轉場),可保留字串 ID。

## 如何設定或抑制

- 啟用本規則(預設關閉):在 `.editorconfig` 設定 `dotnet_diagnostic.UPA2032.severity = suggestion`
- 單一呼叫點:以 `#pragma warning disable UPA2032` / `#pragma warning restore UPA2032` 包住
- 整個專案:設定 `dotnet_diagnostic.UPA2032.severity = none`

## 可設定項

無。

## 相關規則

- UPA2030 回報在每幀方法內建立的 tween(同屬 DOTween 規則群)。
- UPA2031 回報被丟棄且無 `SetLink` 的無限 tween(同屬 DOTween 規則群)。
