# UPA0022 — Enum.HasFlag in per-frame method (deprecated)

> English | [繁體中文](UPA0022.zh-TW.md)

| | |
|---|---|
| Category | Performance |
| Default severity | Warning |
| Enabled by default | No |

## Status

**Deprecated. It reports nothing unless a project turns it on, and every shipped preset
sets it to `none`.** The id is kept because rule ids are never recycled.

## Why it was withdrawn

The rule said `HasFlag` boxes its receiver and its argument, on the grounds that the .NET 5+
JIT intrinsic which removes that boxing does not apply to Unity's Mono. The premise about
.NET is correct. The conclusion drawn from it was not: Mono has special-cased the same-type
call since 4.0 and IL2CPP since Unity 2021.2, both replacing it with a bitwise AND.

Measured on every supported configuration, 200,000 iterations, three repeats, spread under
0.05 ns:

| Runtime | `x.HasFlag(y)` allocation | `x.HasFlag(y)` | `(x & y) == y` |
|---|---|---|---|
| Unity 2022.3, Mono | none | 5.20 ns | 5.38 ns |
| Unity 6, Mono | none | 5.55 ns | 5.02 ns |
| Unity 2022.3, IL2CPP | none | 1.20 ns | 1.58 ns |
| Unity 6, IL2CPP | none | 1.18 ns | 1.59 ns |

No allocation anywhere, and on IL2CPP — the backend a shipped game runs — the call is
faster than the rewrite this rule used to offer as a fix. The code fix has been removed for
that reason: it made the code longer, harder to read, and slower.

## What still costs something

`HasFlag` takes a `System.Enum` parameter, so passing an enum value boxes the argument in
IL. That box is removed along with the call whenever the argument is a plain load, and
survives when branches sit between the load and the call:

```csharp
flags.HasFlag(Rights.Read)          // no allocation (constant)
flags.HasFlag(flag)                 // no allocation (local, parameter, field, property)
flags.HasFlag(cond ? A : B)         // allocates
```

Measured on IL2CPP on both supported editors, against a control that allocates in the same
loop — so the zeros are the elision, not a box hoisted out of the measurement.

**Mono elides less**: there only the constant form is free, and a local, field or property
argument allocates 0.8 B per call on Unity 2022.3 and 2.4 B on Unity 6. UPA0006 follows the
IL2CPP result and stays quiet about all of them.

[UPA0006](UPA0006.md) reports the last of these, at the conversion where it happens, and
stays quiet about the first two.

## If you want it back

Set the severity explicitly and the original behaviour returns:

```ini
dotnet_diagnostic.UPA0022.severity = warning
```

For a Unity build the severity must come from a ruleset rather than `.editorconfig`; see
the ruleset presets shipped with the package.
