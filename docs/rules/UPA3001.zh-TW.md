# UPA3001 — Sockets API unsupported on WebGL

> [English](UPA3001.md) | 繁體中文

| | |
|---|---|
| 類別 | Platform |
| 預設嚴重度 | Warning |
| 預設啟用 | 否 |
| 啟用條件 | 編譯定義了 `UPA_TARGET_WEBGL` |

## 成因

在定義了 `UPA_TARGET_WEBGL` 的編譯中,使用 `System.Net.Sockets` 命名空間中的
任何型別——方法呼叫、實例建構或靜態成員存取。

## 規則說明

瀏覽器不會向網頁程式碼開放原始 socket 存取,因此 `Socket`、`TcpClient`、
`UdpClient` 以及 `System.Net.Sockets` 的其餘型別在 Unity WebGL 建置中會於執行期
失敗。WebGL 上的網路必須透過瀏覽器:HTTP 走 `UnityWebRequest`,
持久連線走 WebSocket 解決方案。

本規則群組只在定義了 `UPA_TARGET_WEBGL` 時執行,且預設停用——請透過
`webgl-addon` preset 啟用。

## 如何修正

- 請求/回應流量 → `UnityWebRequest`。
- 持久雙向連線 → 基於 WebSocket 的傳輸層(多數 Unity 網路堆疊都為 WebGL 提供
  WebSocket 選項)。

## 何時抑制

對已經以 `#if !UNITY_WEBGL` 平台 define 隔離的程式碼路徑,可予以抑制。

## 如何設定或抑制

- 啟用本規則(預設關閉):在 `.editorconfig` 設定 `dotnet_diagnostic.UPA3001.severity = warning`(`webgl-addon` preset 已代為設定)
- 單一位置:`#pragma warning disable UPA3001` / `#pragma warning restore UPA3001`
- 整個專案:設定 `dotnet_diagnostic.UPA3001.severity = none`

## 可設定項

除 `UPA_TARGET_WEBGL` define 外,無其他設定。

## 相關規則

- UPA3000(threading)、UPA3002(同步檔案 IO)、UPA3003(processes)——同一個
  WebGL 群組,共用同一個 define。
