# UPA0023 — OnGUI declared in player code

> [English](UPA0023.md) | 繁體中文

| | |
|---|---|
| 類別 | 效能 |
| 預設嚴重度 | 資訊(Info) |
| 預設啟用 | 否 |

## 成因

在 player 組件中的 `MonoBehaviour` 衍生型別上宣告了 `OnGUI` 方法——
實例方法、回傳 `void`、無參數。

編輯器組件依組件名稱跳過:`Assembly-CSharp-Editor`,
或名稱以 `.Editor` 結尾的任何組件(不分大小寫)。

## 規則說明

`OnGUI` 驅動的是 IMGUI,即 Unity 的即時模式 GUI 系統。Unity 每幀都會呼叫它,
且通常一幀不只一次——layout 與 repaint 是分開的階段,每個輸入事件還會再各觸發一次呼叫。
Unity 手冊指出 IMGUI「is not generally intended to be used for normal in-game user
interfaces」;其列出的用途是遊戲內除錯顯示、自訂 inspector 與編輯器工具——
[IMGUI(Immediate Mode GUI),Unity 手冊](https://docs.unity3d.com/Manual/GUIScriptingGuide.html)。

只要宣告了這個方法,Unity 就會開始呼叫它,因此本規則回報的是宣告本身,
而不是其中的任何特定呼叫。

本規則為 Info 嚴重度且預設停用:開發期 overlay 是 IMGUI 合理且常見的用途,
所以出現 `OnGUI` 是一個「確認意圖」的提示,而非缺陷。
希望以政策禁止玩家介面走 IMGUI 的專案可以啟用它。

編輯器組件的判定以名稱為準。若編輯器組件的名稱不合慣例——
既不是 `Assembly-CSharp-Editor`,也不以 `.Editor` 結尾——會被視為 player 程式碼而被回報;
此時請就地抑制,或把組件改名以符合慣例。

## 如何修正

玩家介面改用 UI Toolkit 或 uGUI 建置。除錯 overlay 可以保留,
但以 define 圍住,讓宣告在正式版 player 中消失:

```csharp
public class StatsOverlay : MonoBehaviour
{
#if ENABLE_DEBUG_OVERLAY
    void OnGUI()
    {
        GUILayout.Label(_frameStats);
    }
#endif
}
```

編輯器工具(自訂 inspector、編輯器視窗)移入編輯器組件,本規則在那裡不會執行。

## 何時抑制

- 刻意保留在開發版 player 中的除錯或作弊 overlay。
- 位於名稱不合慣例的組件中的編輯器工具 `OnGUI` 宣告(見上文)。

## 如何設定或抑制

- 啟用本規則(預設為關閉):在你的 ruleset 中把 UPA0023 設為 `Info` 或更高
- 單一宣告:以 `#pragma warning disable UPA0023` / `#pragma warning restore UPA0023` 包住
- 整個專案:把 UPA0023 設為 `None`

## 可設定項

無。編輯器組件以組件名稱判定,不提供可設定選項。

## 相關規則

- UPA0025 使用相同的名稱式編輯器組件判定,且與本規則一樣回報宣告而非呼叫點。
