# UPA2010 — User-authored async method returns Task

> English | [繁體中文](UPA2010.zh-TW.md)

| | |
|---|---|
| Category | Ecosystem |
| Default severity | Warning |
| Enabled by default | No |
| Active only when | the assembly references UniTask |

## Cause

A user-authored `async` method declaration (including local functions) returns
`System.Threading.Tasks.Task` or `Task<T>`, in an assembly that references UniTask.

## Rule description

Every invocation of an async `Task` method allocates the `Task` object, and awaits that
actually yield box the state machine onto the heap. UniTask provides allocation-free
equivalents (`UniTask`, `UniTask<T>`, `UniTaskVoid`) built for Unity's player loop, so in
a project that has already adopted UniTask, a user-authored `async Task` method is
usually an oversight.

The rule **does not run at all in assemblies that do not reference UniTask** — reporting
advice you cannot act on is worse than staying silent.

Excluded, deliberately:

- **Overrides and interface implementations** (implicit or explicit) — the signature is
  bound by the base declaration and cannot be changed unilaterally.
- **Async lambdas** — the delegate type is decided by the consuming API.
- **Non-async `Task`-returning methods** — forwarding/wrapper methods allocate no state
  machine of their own.

## How to fix violations

```csharp
// Before
async Task LoadAsync()
{
    await UniTask.Yield();
}

// After
async UniTask LoadAsync()
{
    await UniTask.Yield();
}
```

For fire-and-forget entry points prefer `async UniTaskVoid` (see UPA2012). Keep `Task`
only on boundaries that third-party code consumes.

## When to suppress warnings

Suppress on public API surfaces consumed by code that expects `Task` (libraries,
test frameworks, non-Unity callers).

## How to configure or suppress

- Enable the rule (it is off by default): `dotnet_diagnostic.UPA2010.severity = warning` in `.editorconfig`
- Single method: wrap the declaration in `#pragma warning disable UPA2010` / `#pragma warning restore UPA2010`
- Whole project: set `dotnet_diagnostic.UPA2010.severity = none`

## Configuration

None. The UniTask presence check is by referenced assembly name (`UniTask`).

## Related rules

- UPA2012 covers `async void` and unawaited fire-and-forget calls.
