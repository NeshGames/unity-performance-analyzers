# UPA0002 — Object name or tag accessed in per-frame method

> English | [繁體中文](UPA0002.zh-TW.md)

| | |
|---|---|
| Category | Performance |
| Default severity | Warning |
| Enabled by default | Yes |

## Cause

The getter of `UnityEngine.Object.name`, `UnityEngine.GameObject.tag`, or
`UnityEngine.Component.tag` is read inside a per-frame hot path: a hot Unity message such
as `Update`, `FixedUpdate`, or `LateUpdate` on a `MonoBehaviour`-derived type, or a method
marked with a hot-path attribute such as `[HotPath]`.

## Rule description

Both getters call into Unity's native engine code and return a newly allocated managed
string on every access — the value is not cached on the managed side. Reading them every
frame therefore produces garbage each frame and adds native-call overhead.

Reads that are an operand of `==` or `!=` against a string are deliberately **not**
reported: that pattern is covered by `UNT0002` (Microsoft.Unity.Analyzers), which suggests
`CompareTag`. Reading the value into a local first (`var t = tag; if (t == "A")`) escapes
that division and is reported by this rule.

A `switch` on `tag` is reported in v0.1; this may be revisited based on feedback.

## How to fix violations

Use `CompareTag` for tag comparisons, or read the value once outside the hot path and cache
it.

Before:

```csharp
void Update()
{
    if (other.gameObject.name == cachedName || Check(gameObject.name))
    {
    }
}
```

After:

```csharp
string _name;

void Awake()
{
    _name = gameObject.name;
}

void Update()
{
    if (_name == cachedName || Check(_name))
    {
    }
}
```

## When to suppress warnings

Suppress when the object is renamed or retagged between frames and the current value is
genuinely needed each frame, or in editor-only tooling code where per-frame cost is
irrelevant.

## How to configure or suppress

- Single call site: wrap it in `#pragma warning disable UPA0002` / `#pragma warning restore UPA0002`
- Whole project: set `dotnet_diagnostic.UPA0002.severity = suggestion` (or `none`) in `.editorconfig`
- By path: the shipped presets relax rules under `[**/Editor/**/*.cs]`; add similar sections for tooling or generated code
- Hot-path classification: adjust the `upa_hot_path_*` options below

## Configuration

The hot-path classification is shared and configurable via `.editorconfig`:

```ini
upa_hot_path_messages = Update,FixedUpdate,LateUpdate,OnTriggerEnter
upa_hot_path_attributes = HotPath,PerfCritical
upa_hot_path_include_lambdas = true
```

## Related rules

- `UNT0002` (Microsoft.Unity.Analyzers) covers `tag == "..."` / `name == "..."` style
  comparisons and offers a `CompareTag` code fix. UPA0002 defers to it for that pattern.
