# UPA0010 — Raycast without explicit maxDistance or layerMask

> English | [繁體中文](UPA0010.zh-TW.md)

| | |
|---|---|
| Category | Performance |
| Default severity | Warning |
| Enabled by default | Yes |

## Cause

A call to `UnityEngine.Physics.Raycast`, `Physics.RaycastAll`, or
`Physics.RaycastNonAlloc` (including the `Ray`-based overloads) resolves to an overload
that lacks a `maxDistance` or `layerMask` parameter — or both.

## Rule description

Omitting `maxDistance` makes the query extend to infinity; omitting `layerMask` makes it
test every layer, including trigger colliders and layers that were never meant to be hit.
Both defaults make the query cost scale with the whole scene, and the all-layers default is
also a frequent source of hard-to-debug wrong-hit behavior.

The rule is deliberately strict — it fires when *either* argument is missing. When hitting
all layers really is intended, state it explicitly with `~0`; that keeps the intent visible
and satisfies the rule.

`Physics2D` and the shape-cast family (`SphereCast`, `BoxCast`, `CapsuleCast`) are not
covered in v0.1.

## How to fix violations

Before:

```csharp
if (Physics.Raycast(origin, direction, out var hit))
{
}
```

After:

```csharp
if (Physics.Raycast(origin, direction, out var hit, interactRange, _interactableMask))
{
}

// Or, when every layer is genuinely intended:
if (Physics.Raycast(origin, direction, out var hit, interactRange, ~0))
{
}
```

## When to suppress warnings

Suppress in editor tooling or one-shot debug queries where scene-wide scanning is
acceptable and intentional.

## How to configure or suppress

- Single call site: wrap it in `#pragma warning disable UPA0010` / `#pragma warning restore UPA0010`
- Whole project: set `dotnet_diagnostic.UPA0010.severity = suggestion` (or `none`) in `.editorconfig`
- By path: the shipped presets relax rules under `[**/Editor/**/*.cs]`; add similar sections for tooling or generated code

## Configuration

None.
