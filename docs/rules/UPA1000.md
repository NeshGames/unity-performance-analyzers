# UPA1000 — Leaf class not sealed

> English | [繁體中文](UPA1000.zh-TW.md)

| | |
|---|---|
| Category | Correctness |
| Default severity | Warning |
| Enabled by default | No |

## Cause

A concrete class (not `abstract`, not `static`) is not `sealed`, has no derived types in
the compilation, and declares no `virtual` members of its own.

## Rule description

When a class is sealed, the runtime and the IL2CPP compiler can replace virtual dispatch
on it with direct calls and enable further inlining, because no derived type can exist.
For a leaf class, adding `sealed` is a zero-semantic-cost improvement that also states
design intent. This applies to `MonoBehaviour` subclasses too — Unity does not require
them to be inheritable.

Exclusions:

- Classes declaring their own `virtual` (non-`override`) members: sealing them is a
  compile error (CS0549), and an as-yet-unused extension point may be intentional.
- `abstract` and `static` classes; structs are implicitly sealed.

**Known limitation**: the analysis is scoped to one compilation. A `public` type could be
derived from another assembly, which this rule cannot see — game code assemblies are
rarely inherited externally, but suppress the diagnostic where that is the design.

The rule is **disabled by default** because it reports at type granularity across the
whole codebase; presets grade it as `suggestion` / `warning`.

## How to fix violations

```csharp
// Before
public class PlayerMover : MonoBehaviour { }

// After
public sealed class PlayerMover : MonoBehaviour { }
```

## When to suppress warnings

Suppress for types that are intended extension points for other assemblies (public plugin
APIs, types consumed by serializers or mocking frameworks that require proxies).

## How to configure or suppress

- Enable the rule (it is off by default): `dotnet_diagnostic.UPA1000.severity = warning` in `.editorconfig`
- Single type: wrap the declaration in `#pragma warning disable UPA1000` / `#pragma warning restore UPA1000`
- Whole project: set `dotnet_diagnostic.UPA1000.severity = none`

## Configuration

None.

## Related rules

- None. `UNT####` rules do not cover sealing.
