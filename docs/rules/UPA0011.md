# UPA0011 — SetActive used to toggle UI visibility

> English | [繁體中文](UPA0011.zh-TW.md)

| | |
|---|---|
| Category | Performance |
| Default severity | Warning |
| Enabled by default | No |

## Cause

`SetActive` is called through a UI component's `gameObject` — the exact shape
`uiComponent.gameObject.SetActive(...)` where the receiver is statically typed as a
`UnityEngine.UI.Graphic` derivative (Image, Text, RawImage, …) or a `TMPro.TMP_Text`
derivative.

## Rule description

`SetActive(false)` deactivates the entire GameObject. Reactivating it runs `OnEnable` and
forces the canvas to rebuild the element's geometry, which is substantially more work than
the visual toggle usually intended. Disabling the component (`enabled = false`) or driving
a `CanvasGroup.alpha` achieves the same visual result at a much lower reactivation cost.

The heuristic is deliberately narrow — **disabled by default** and only reporting when the
receiver is statically known to be a UI component:

- A plain `gameObject.SetActive(...)` is never reported: whether that object is UI cannot
  be judged statically, and toggling whole panels via `SetActive` (to also stop layout and
  raycasts) is often intentional.
- Each branch registers only when its type (`UnityEngine.UI.Graphic` / `TMPro.TMP_Text`)
  exists in the compilation, so projects without uGUI or TextMeshPro pay nothing.

## How to fix violations

Before:

```csharp
void SetHealthVisible(bool visible)
{
    _healthIcon.gameObject.SetActive(visible);
}
```

After:

```csharp
void SetHealthVisible(bool visible)
{
    _healthIcon.enabled = visible;
}

// Or, for groups of elements:
_healthGroup.alpha = visible ? 1f : 0f;
_healthGroup.blocksRaycasts = visible;
```

## When to suppress warnings

Suppress when deactivating the whole GameObject is the point — for example the element has
scripts or colliders that must stop running while hidden.

## How to configure or suppress

- Enable the rule (it is off by default): `dotnet_diagnostic.UPA0011.severity = warning` in `.editorconfig`
- Single call site: wrap it in `#pragma warning disable UPA0011` / `#pragma warning restore UPA0011`
- Whole project: set `dotnet_diagnostic.UPA0011.severity = none`

## Configuration

None.
