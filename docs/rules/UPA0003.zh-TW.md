# UPA0003 — String-based shader or animator property access

> [English](UPA0003.md) | 繁體中文

| | |
|---|---|
| 類別 | 效能 |
| 預設嚴重度 | 警告(Warning) |
| 預設啟用 | 是 |

## 成因

以字串字面值或編譯期常數作為名稱引數,呼叫了
`Material.Set*/Get*/HasProperty`、`MaterialPropertyBlock.Set*/Get*`、
`Shader.SetGlobal*/GetGlobal*` 或
`Animator.Play/CrossFade/CrossFadeInFixedTime/Set*/Get*/ResetTrigger`
的字串版多載。

## 規則說明

這些 API 同時接受屬性/狀態名稱字串或整數 ID。字串版多載每次呼叫都要把名稱轉換成 ID;
整數版多載則完全跳過這個轉換。Unity 提供 `Shader.PropertyToID` 與
`Animator.StringToHash`,讓轉換只做一次、之後重複使用轉換出的 ID。

本規則預設**不**限定於熱路徑:它的目標是把屬性 ID 集中到一個 static 類別,
這是專案結構層面的考量,而不是單一熱點的考量。
設定 `upa_shader_property_hot_path_only = true` 可縮小範圍。

名稱引數為非常數運算式的呼叫不會被回報——該值可能是資料驅動的,無法靜態快取。
`Shader.PropertyToID` 與 `Animator.StringToHash` 本身永遠不會被回報。
Shader keyword 相關 API(`EnableKeyword` 等)在 v0.1 不在範圍內。

## 如何修正

在一個 static 快取類別中把每個名稱解析一次,並改用整數版多載。

修正前:

```csharp
void Apply(Material mat)
{
    mat.SetFloat("_Alpha", 0.5f);
    _animator.Play("Idle");
}
```

修正後:

```csharp
static class ShaderProperty
{
    public static readonly int Alpha = Shader.PropertyToID("_Alpha");
}

static class AnimatorState
{
    public static readonly int Idle = Animator.StringToHash("Idle");
}

void Apply(Material mat)
{
    mat.SetFloat(ShaderProperty.Alpha, 0.5f);
    _animator.Play(AnimatorState.Idle);
}
```

## 何時抑制

在呼叫次數微不足道的一次性 editor 工具或除錯工具中,
或某屬性刻意只在初始化時存取一次、加入快取類別只會徒增間接層而無益處時,
可以抑制此警告。

## 如何設定或抑制

- 單一呼叫點:以 `#pragma warning disable UPA0003` / `#pragma warning restore UPA0003` 包住
- 整個專案:在 `.editorconfig` 設定 `dotnet_diagnostic.UPA0003.severity = suggestion`(或 `none`)
- 依路徑:隨附的 preset 已放寬 `[**/Editor/**/*.cs]` 下的規則;可為工具程式碼或產生的程式碼加入類似區段
- 範圍:設定 `upa_shader_property_hot_path_only = true` 可把本規則限定於每幀熱路徑

## 可設定項

```ini
# Narrow the rule to per-frame hot paths only (default: false)
upa_shader_property_hot_path_only = false

# Target classes used by the future code fix (v1.0)
upa_shader_property_cache_class = ShaderProperty
upa_animator_state_cache_class = AnimatorState
```

## 相關規則

- `UNT0041`(Microsoft.Unity.Analyzers)只在偵測到重複時才涵蓋重複的字串版 `Animator`
  呼叫。UPA0003 會回報任何常數字串用法,兩者可以共存;
  若不想要這種重疊,可透過 `.editorconfig` 抑制其中一條。
