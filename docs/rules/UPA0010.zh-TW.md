# UPA0010 — Raycast without explicit maxDistance or layerMask

> [English](UPA0010.md) | 繁體中文

| | |
|---|---|
| 類別 | Performance |
| 預設嚴重度 | Warning |
| 預設啟用 | 是 |

## 成因

對 `UnityEngine.Physics.Raycast`、`Physics.RaycastAll` 或
`Physics.RaycastNonAlloc` 的呼叫(包含以 `Ray` 為參數的多載)解析到了缺少
`maxDistance` 或 `layerMask` 參數——或兩者皆缺——的多載。

## 規則說明

省略 `maxDistance` 會讓查詢延伸到無限遠;省略 `layerMask` 則會讓它測試所有 layer,
包括 trigger collider 以及原本就不該被打到的 layer。這兩個預設值都會讓查詢成本隨整個
場景規模放大,而「打到所有 layer」的預設也是難以除錯的錯誤命中行為的常見來源。

本規則刻意從嚴——只要*任一*引數缺失就會觸發。當「打到所有 layer」確實是本意時,
請以 `~0` 明確寫出;這既讓意圖清楚可見,也能滿足本規則。

`Physics2D` 與形狀投射家族(`SphereCast`、`BoxCast`、`CapsuleCast`)不在 v0.1 的
涵蓋範圍內。

## 如何修正

修正前:

```csharp
if (Physics.Raycast(origin, direction, out var hit))
{
}
```

修正後:

```csharp
if (Physics.Raycast(origin, direction, out var hit, interactRange, _interactableMask))
{
}

// Or, when every layer is genuinely intended:
if (Physics.Raycast(origin, direction, out var hit, interactRange, ~0))
{
}
```

## 何時抑制

在編輯器工具或一次性的除錯查詢中,若掃描整個場景是可接受且刻意的行為,可以抑制。

## 如何設定或抑制

- 單一呼叫位置:以 `#pragma warning disable UPA0010` / `#pragma warning restore UPA0010` 包住
- 整個專案:在 `.editorconfig` 設定 `dotnet_diagnostic.UPA0010.severity = suggestion`(或 `none`)
- 依路徑:隨附的 preset 會在 `[**/Editor/**/*.cs]` 底下放寬規則;可為工具程式碼或產生的程式碼加入類似的區段

## 可設定項

無。

## 相關規則

- 無。`UNT####` 規則並未涵蓋 raycast 的範圍限定。
