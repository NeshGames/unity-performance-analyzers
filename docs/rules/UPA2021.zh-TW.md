# UPA2021 — Public Action event used for observable state

> [English](UPA2021.md) | 繁體中文

| | |
|---|---|
| 類別 | Ecosystem |
| 預設嚴重度 | Warning |
| 預設啟用 | 否 |
| 啟用條件 | 該 assembly 引用 R3 |

## 成因

在引用 R3 的 assembly 中,存在 `public` 的欄位式(field-like)事件,其委派型別屬於
`System.Action` 家族(`Action`、`Action<T>`、`Action<T1, T2>`、…)。

## 規則說明

公開的 `Action` 事件是「此狀態已改變」通知的慣用寫法。純事件不提供訂閱端任何
組合能力(過濾、節流、合併)、沒有目前值(current-value)語意,且需要手動退訂、
容易造成洩漏——在 Unity 中這是懸掛引用的常見來源,因為訂閱者的生命週期跟隨場景物件。
R3 的 `ReactiveProperty` 與 `Observable` 提供可組合、可釋放(disposable)的訂閱,
並具有明確的順序。

判斷準則**刻意收窄**,且本規則**只在引用 R3 的 assembly 中執行**:

- `EventHandler` / `EventHandler<T>` 事件——.NET 既定模式,不回報。
- 非公開事件——內部實作細節,不回報。
- 自訂委派型別——可能承載既有的 API 契約,不回報。
- 純 `Action` 欄位或屬性(非事件)——回呼用法,不回報。
- 自訂 `add`/`remove` 的事件——可能包裝既有契約,不回報。

## 如何修正

```csharp
// Before
public event Action<int> ScoreChanged;

// After
public ReactiveProperty<int> Score { get; } = new(0);
// subscribers: score.Score.Subscribe(v => ...).AddTo(this);
```

當通知沒有目前值時,使用 `Observable`/`Subject<T>`。在會被無法引入 R3 相依的
程式碼使用的 API 介面上,保留純事件。

## 何時抑制

在有非 R3 使用端的公開 API 邊界上抑制,或在需要 Unity 序列化/Inspector
接線事件模式的地方抑制。

## 如何設定或抑制

- 啟用本規則(預設關閉):在 `.editorconfig` 設定 `dotnet_diagnostic.UPA2021.severity = warning`
- 單一事件:以 `#pragma warning disable UPA2021` / `#pragma warning restore UPA2021` 包住宣告
- 整個專案:設定 `dotnet_diagnostic.UPA2021.severity = none`

## 可設定項

無。R3 是否存在以引用的 assembly 名稱(`R3`)判斷。

## 相關規則

- 無。`UNT####` 規則未涵蓋事件建模。
