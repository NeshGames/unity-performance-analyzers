# UPA3003 — Process API unsupported on WebGL

> [English](UPA3003.md) | 繁體中文

| | |
|---|---|
| 類別 | Platform |
| 預設嚴重度 | Warning |
| 預設啟用 | 否 |
| 啟用條件 | 編譯定義了 `UPA_TARGET_WEBGL` |

## 成因

在定義了 `UPA_TARGET_WEBGL` 的編譯中,使用 `System.Diagnostics.Process`——
方法呼叫、實例建構或靜態成員存取。

## 規則說明

瀏覽器無法啟動或檢視作業系統程序,因此所有 `Process` API 在 Unity WebGL 建置中
都會於執行期失敗。遊戲 assembly 中的這類程式碼通常是從未做平台隔離的
桌面限定輔助功能(開啟資料夾、啟動外部工具)。

本規則群組只在定義了 `UPA_TARGET_WEBGL` 時執行,且預設停用——請透過
`webgl-addon` preset 啟用。

## 如何修正

- 開啟 URL → `Application.OpenURL`,在包含 WebGL 的所有平台上都可運作。
- 桌面限定的輔助功能 → 以 `#if UNITY_STANDALONE` 隔離(或移到 Editor assembly),
  並提供適合 WebGL 的替代方案,或省略該功能。

## 何時抑制

對已經以 `#if !UNITY_WEBGL` 平台 define 隔離的程式碼路徑,可予以抑制。

## 如何設定或抑制

- 啟用本規則(預設關閉):在 `.editorconfig` 設定 `dotnet_diagnostic.UPA3003.severity = warning`(`webgl-addon` preset 已代為設定)
- 單一位置:`#pragma warning disable UPA3003` / `#pragma warning restore UPA3003`
- 整個專案:設定 `dotnet_diagnostic.UPA3003.severity = none`

## 可設定項

除 `UPA_TARGET_WEBGL` define 外,無其他設定。

## 相關規則

- UPA3000(threading)、UPA3001(sockets)、UPA3002(同步檔案 IO)——同一個
  WebGL 群組,共用同一個 define。
