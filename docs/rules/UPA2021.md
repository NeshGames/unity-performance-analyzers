# UPA2021 — Public Action event used for observable state

> English | [繁體中文](UPA2021.zh-TW.md)

| | |
|---|---|
| Category | Ecosystem |
| Default severity | Warning |
| Enabled by default | No |
| Active only when | the assembly references R3 |

## Cause

A `public` field-like event whose delegate type belongs to the `System.Action` family
(`Action`, `Action<T>`, `Action<T1, T2>`, …), in an assembly that references R3.

## Rule description

A public `Action` event is the idiomatic shape for "this state changed" notification.
Plain events give subscribers no composition (filtering, throttling, combining), no
current-value semantics, and manual unsubscription that is easy to leak — a common
source of dangling references in Unity, where subscriber lifetimes follow scene objects.
R3's `ReactiveProperty` and `Observable` provide composable, disposable subscriptions
with explicit ordering.

The heuristic is **deliberately narrow** and the rule runs **only in assemblies that
reference R3**:

- `EventHandler` / `EventHandler<T>` events — the established .NET pattern, not reported.
- Non-public events — internal implementation detail, not reported.
- Custom delegate types — may carry an established API contract, not reported.
- Plain `Action` fields or properties (not events) — callback usage, not reported.
- Custom `add`/`remove` events — may wrap an existing contract, not reported.

## How to fix violations

```csharp
// Before
public event Action<int> ScoreChanged;

// After
public ReactiveProperty<int> Score { get; } = new(0);
// subscribers: score.Score.Subscribe(v => ...).AddTo(this);
```

Use `Observable`/`Subject<T>` when the notification has no current value. Keep the plain
event on API surfaces consumed by code that cannot take an R3 dependency.

## When to suppress warnings

Suppress on public API boundaries with non-R3 consumers, or where a Unity-serialized /
inspector-wired event pattern is required.

## How to configure or suppress

- Enable the rule (it is off by default): `dotnet_diagnostic.UPA2021.severity = warning` in `.editorconfig`
- Single event: wrap the declaration in `#pragma warning disable UPA2021` / `#pragma warning restore UPA2021`
- Whole project: set `dotnet_diagnostic.UPA2021.severity = none`

## Configuration

None. The R3 presence check is by referenced assembly name (`R3`).

## Related rules

- None. `UNT####` rules do not cover event modeling.
