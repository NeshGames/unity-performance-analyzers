# UPA0021 — 用 sqrMagnitude 就夠的 magnitude 或 Distance 比較

> [English](UPA0021.md) | 繁體中文

| | |
|---|---|
| 類別 | Performance |
| 預設嚴重度 | Warning |
| 預設啟用 | 是 |

## 成因

關係比較(`<`、`<=`、`>`、`>=`)中,恰好有一側是
`Vector2` / `Vector3` / `Vector4` 的 `magnitude` 屬性存取,或靜態的
`Vector2.Distance(...)` / `Vector3.Distance(...)` / `Vector4.Distance(...)` 呼叫:

```csharp
if (transform.position.magnitude < 5f) { ... }
if (Vector3.Distance(a, b) < radius) { ... }
```

**兩側**都是 magnitude 或 `Distance` 運算式的比較不會回報——
兩側都開平方根,改寫雖然保持比較結果,卻省不到任何東西。
相等運算子也不在範圍內;只有次序比較改為對平方後的門檻值比較時,意義才得以保持。

## 規則說明

`magnitude` 與 `Distance` 方法都會計算平方根。當結果只拿來與門檻值比較時,
這個平方根是白做的工:「Calculating the squared magnitude instead of using the
magnitude property is much faster - the calculation is basically the same only without
the slow Sqrt call. If you are using magnitudes simply to compare distances, then you
can just as well compare squared magnitudes against the squares of distances since the
comparison will give the same result」——
[Unity Scripting API, Vector3.sqrMagnitude](https://docs.unity3d.com/ScriptReference/Vector3-sqrMagnitude.html)。

本規則不限於逐幀熱路徑——距離判斷集中在多半逐幀執行的 gameplay 程式碼裡,
而且這個改寫在可讀性上沒有代價。

診斷訊息為:「Comparing '{0}' computes a square root. Compare sqrMagnitude against the
squared threshold instead.」

## 修正方式

改為以 `sqrMagnitude` 與平方後的門檻值比較:

修正前:

```csharp
if (transform.position.magnitude < 5f) { ... }
if (Vector3.Distance(a, b) < radius) { ... }
```

修正後:

```csharp
if (transform.position.sqrMagnitude < 25f) { ... }
if ((a - b).sqrMagnitude < radius * radius) { ... }
```

當另一側是單純的數字常值時,會提供 code fix(「Compare sqrMagnitude against the
squared threshold」):把 `v.magnitude` 改寫為 `v.sqrMagnitude`、把
`Vector3.Distance(a, b)` 改寫為 `(a - b).sqrMagnitude`,並把常值平方
(`5f` 變成 `25f`)。單純常值在語法上必然非負;負的門檻值是以一元負號寫成的
(`-1f`),這種形態不提供修正,因為平方會改變比較的意義。非常值的門檻
(欄位、參數、運算式)同樣沒有自動修正——請自行平方,如上例的
`radius * radius`。

## 何時可以抑制

當門檻值是執行期可能為負的數值時可以抑制——例如帶正負號的設定值,
`magnitude > threshold` 的本意是門檻降到零以下時對任何向量都成立。
把這種門檻平方會改變比較的意義,所以回報建議的改寫並不適用。
以清晰為先的冷程式碼(編輯器工具、一次性驗證)也適合保留 `magnitude`。

## 設定與抑制方式

- 單一呼叫位置:以 `#pragma warning disable UPA0021` / `#pragma warning restore UPA0021` 包住
- 整個專案:在 `.editorconfig` 設定 `dotnet_diagnostic.UPA0021.severity = suggestion`(或 `none`)
- 依路徑:隨附的 preset 已放寬 `[**/Editor/**/*.cs]` 下的規則;可為工具程式碼或產生的程式碼加入類似區段

## 可設定項

無。
