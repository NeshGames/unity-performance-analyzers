# UPA2001 — System.Linq usage in per-frame method

> English | [繁體中文](UPA2001.zh-TW.md)

| | |
|---|---|
| Category | Ecosystem |
| Default severity | Warning |
| Enabled by default | No |

## Cause

A call to an extension method declared on `System.Linq.Enumerable` or
`System.Linq.Queryable` **inside a per-frame hot path** — method syntax or query syntax
(`from x in list select x`), which compiles into the same methods.

## Rule description

LINQ operators allocate enumerator objects, delegate instances, and often intermediate
collections on every evaluation. In general .NET code that cost is a fine trade for
readability; inside methods that Unity runs every frame it is steady garbage that is
invisible at the call site.

The rule only looks at hot paths (`Update`, `FixedUpdate`, and the rest of the shared
hot-path classification) — one-shot and initialization LINQ stays legal. It is still
**disabled by default** and enabled by the `cysharp-stack` preset, because banning LINQ
even there is a codebase discipline choice.

Same-named extension methods on your own types (a custom `Where`) are excluded by
declaring-type comparison.

## How to fix violations

Replace the operator chain with an explicit loop:

```csharp
// Before
var active = units.Where(u => u.IsActive).ToList();

// After
var active = new List<Unit>();
for (var i = 0; i < units.Count; i++)
{
    if (units[i].IsActive)
    {
        active.Add(units[i]);
    }
}
```

Hoist the result list out of the method and reuse it (see UPA0006).

## When to suppress warnings

Suppress on cold branches inside hot methods (rare state transitions, debug-only paths)
where the query provably runs infrequently.

## How to configure or suppress

- Enable the rule (it is off by default): set UPA2001 to `Warning` in your ruleset
- Single call site: wrap it in `#pragma warning disable UPA2001` / `#pragma warning restore UPA2001`
- Hot-path classification: adjust the shared `upa_hot_path_*` options (IDE only; see UPA0006)
- Whole project: set UPA2001 to `None`

## Configuration

Hot-path classification is shared and configurable via `.editorconfig` (IDE only):

```ini
upa_hot_path_messages = Update,FixedUpdate,LateUpdate
upa_hot_path_attributes = HotPath,PerfCritical
upa_hot_path_include_lambdas = true
```

## Related rules

- UPA0006 reports the underlying allocations on per-frame hot paths.
- UPA0007 reports the capturing lambdas that LINQ predicates frequently are.
