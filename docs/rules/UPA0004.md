# UPA0004 — Instantiating accessor used in per-frame method

> English | [繁體中文](UPA0004.zh-TW.md)

| | |
|---|---|
| Category | Performance |
| Default severity | Warning |
| Enabled by default | Yes |

## Cause

The getter of `UnityEngine.Renderer.material`, `UnityEngine.Renderer.materials`, or
`UnityEngine.MeshFilter.mesh` is read inside a per-frame hot path: a hot Unity message such
as `Update`, `FixedUpdate`, or `LateUpdate` on a `MonoBehaviour`-derived type, or a method
marked with a hot-path attribute such as `[HotPath]`. Derived types such as
`SkinnedMeshRenderer` are covered because the accessors resolve to their declaring type.

## Rule description

To be precise about what these accessors cost — they are not "an allocation every frame":

1. `Renderer.material` and `MeshFilter.mesh` duplicate the shared asset on **first** access
   and cache the instance; later accesses return the same instance. The caller owns that
   copy and must destroy it manually (`Destroy(instance)`), or it leaks.
2. Every access — first or not — is still a native property call, which is avoidable cost
   on a per-frame path.
3. `Renderer.materials` (plural) returns a **newly allocated array on every access**.

The `sharedMaterial` / `sharedMaterials` / `sharedMesh` accessors do not create copies and
are not reported — use them when mutating the shared asset is intended.

## How to fix violations

Cache the instance in a field outside the hot path and release it in `OnDestroy`.

Before:

```csharp
void Update()
{
    _renderer.material.color = _currentColor;
}
```

After:

```csharp
Material _material;

void Awake()
{
    _material = _renderer.material;
}

void Update()
{
    _material.color = _currentColor;
}

void OnDestroy()
{
    Destroy(_material);
}
```

## When to suppress warnings

Suppress when the renderer's material set genuinely changes between frames and the current
instance must be re-fetched, or in editor tooling where per-frame cost and instance
lifetime are managed elsewhere.

## How to configure or suppress

- Single call site: wrap it in `#pragma warning disable UPA0004` / `#pragma warning restore UPA0004`
- Whole project: set `<Rule Id="UPA0004" Action="Info" />` (or `None`) in `Assets/Default.ruleset`
- By assembly: copy `editor-relaxed.ruleset` into an Editor asmdef folder as `Default.ruleset`; a `Default.ruleset` in a tooling or generated-code asmdef folder works the same way
- Hot-path classification: adjust the `upa_hot_path_*` options below

## Configuration

The hot-path classification is shared and set in the universal options file `Assets/Rules.UnityPerformanceAnalyzers.additionalfile` (the same `key = value` lines also work in an `.editorconfig` passed to `upa-cli --editorconfig`):

```ini
upa_hot_path_messages = Update,FixedUpdate,LateUpdate,OnTriggerEnter
upa_hot_path_attributes = HotPath,PerformanceCritical
upa_hot_path_include_lambdas = true
```
