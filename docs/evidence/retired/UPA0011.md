# UPA0011 retirement evidence

UPA0011 reported `uiComponent.gameObject.SetActive(...)` and suggested replacing it with
`Graphic.enabled` or a `CanvasGroup`.

The audit retired the rule because that rewrite is not semantics-preserving. Deactivating a
GameObject stops every attached component and child hierarchy according to Unity activation
semantics; disabling one graphic or changing alpha does not. The analyzer can see the receiver's
static UI type, but it cannot prove that visibility is the only intended effect.

That makes the finding a design preference rather than a near-universal agent fix. Keeping it in a
CI profile would require repeated human intent checks, which conflicts with the agent-first policy.

The diagnostic ID remains reserved and must not be reused.
